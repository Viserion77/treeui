<Title>Patterns</Title>

TreeUI treats some repeated app UI as composition recipes instead of standalone exports.
These patterns matter, but they stay docs-first until they prove they need their own semantic API,
state model, or accessibility contract. The rules that decide when a recipe graduates into an export
live in <a target="_top" href="./?path=/docs/foundation-conventions--docs">Conventions</a>.

Each row below links to a rendered example in the `Patterns/Recipes` story group; open the story and
use **Show code** for the exact markup, so this page never carries a second copy of it.

| Pattern | Compose from | Live example |
|---|---|---|
| Stat group | `TGrid` + `TStat` | <a target="_top" href="./?path=/docs/patterns-recipes-dashboard-metric-grid--docs">Dashboard metric grid</a> |
| Section header | heading + `TStack` + optional `TBadge` / `TButton` | <a target="_top" href="./?path=/story/patterns-recipes--section-header">Section header</a> |
| Subpanel | `TCard`, especially `variant="soft"` | <a target="_top" href="./?path=/story/patterns-recipes--subpanel">Subpanel</a> |

| Eyebrow text | Typography recipe using existing text and spacing tokens | <a target="_top" href="./?path=/story/patterns-recipes--eyebrow-text">Eyebrow text</a> |

## When to reach for each

- **Stat group** — a dashboard or admin surface needs a compact block of metrics with equal visual weight.
- **Section header** — a page section needs a title, support copy, and one or two actions without a wrapper component.
- **Subpanel** — content needs a quieter container inside a larger page section or shell.
- **Stacked card** — a card repeats the same header, metadata, and action rhythm across lists, boards, or dashboards.
- **Eyebrow text** — a small label helps orient the user before a larger title or content block.
- **Form stack** — forms need predictable vertical rhythm and responsive grouping without another layout abstraction.
- **Ranking** — the UI is really about ordered comparison rather than a new component family. Use `TSelectableList` instead of `TTable` for smaller ranked sets with richer row templates.
- **Action panel** — an area combines context, status, and a small cluster of actions around a single decision.

The `Patterns/Recipes` group also carries larger, fully interactive compositions — application shells,
searchable multi-choice fields, destructive-confirmation flows, and more. The machine-readable list of
every recipe, with its `compose` set and notes, is `docs/ai/RECIPES.yaml`.
